# Ends of the Earth: code review, 2026-11-09

Scope: built site at 3a88bedd. Read-only.

## 1. Summary for the owner

The code is careful and better than most hobby projects. Midnight rollover, two-tab conflicts and mid-round reloads are handled on purpose. The real risks are not bugs in the game loop. They are: the game runs out of puzzles on 12 January 2027; moving to a new domain will wipe every player's streak and passport unless you build an import path first; and the country map file is 2.5 MB over the wire, which is slow on phones. An iOS app is possible, but a plain web wrapper will likely be rejected by Apple.

## 2. Findings

### Critical

**C1. Content runs out on 2027-01-12.** `config.json:2` sets `day1` to 2026-10-27. `data/manifest.json:2` has 78 decks. `game.js:39` returns `status: 'after'` past deck 78, and the home screen then reads "Expedition #78 was the last one dealt." Check: `date -d "2026-10-27 +77 days"` gives 2027-01-12. About 9 weeks left. Decks come from the private repo. Cost: S if made, M if not.

**C2. A domain move loses all player progress.** Every record lives in `localStorage` under `ends:` (`rules.js:295`). Browsers scope storage to the origin, so a new domain starts empty. There is an export (`store.js:73`, `menu.js:367`) but no import. The key `keys.imported` (`rules.js:305`) exists and is never used. Fix: add import, and a one-time handoff link from the old site to the new one, before the move. Cost: M.

### Major

**M1. Map data is heavy and blocks start.** `data/countries.json` is 8.7 MB raw, 2.5 MB gzipped (measured on staging: 2,533,022 bytes). It is Natural Earth 1:10m at 0.001 degree precision. It is loaded in the startup `Promise.all` (`app.js:53`), so nothing plays until it arrives. Fix: 1:50m or simplify, and split hit-test data from draw data. Cost: M.

**M2. MapLibre is a blocking script.** `index.html:25` loads 803 KB (211 KB gzipped) in `<head>` with no `defer`. It holds up first paint. Fix: `defer` it, or import it from `app.js`. Cost: S.

**M3. The domain is hard-coded in about 23,330 files.** `rules.js:265` (`SITE_URL`), `index.html:17-18`, and every `s/*.html` page (23,328 of them, not 7,776: 7,776 score codes times 3 variants) point at `bjepp77.github.io`. Check: `grep -rl bjepp77.github.io s | wc -l`. Share links already sent keep working only while GitHub Pages stays up. Fix: make the base URL a build setting; keep Pages alive as a redirect. Cost: S in the private build, L by hand here.

**M4. No security headers.** No CSP anywhere (`grep -rn Content-Security` finds nothing). GitHub Pages cannot send headers, so this is new work for step 2. Share pages use an inline `location.replace` script, so a strict CSP needs a hash or a meta refresh. Low practical risk today: `innerHTML` only takes built-in constants (`menu-art.js:61`, `tour.js:14`). Cost: S.

**M5. No tests in this repo.** `store.js:1` refers to node tests that live in the private repo. Nothing here catches a regression.

### Minor

**m1. Storage schema has a version but no migration.** `newOwner` writes `storage: 1` (`rules.js:318`) and keys say `record:v1`, but nothing reads the version. Keys `asked` and `corrected` are also unused. Cost: S.

**m2. Timer trusts the device clock.** Rounds use `Date.now()` (`app.js:465`, `rules.dropAccepted`). Moving the clock back gives more time; moving the date forward opens future decks. All deck answers are public JSON anyway (`data/decks/day-0NN.json`). Fine until there is a leaderboard.

**m3. One cache key for every file.** All assets share `?v=347fb2353f`, so any release busts the whole cache. `countries.json` and decks have no `?v` and use `cache: 'no-cache'` (`app.js:28`, `map.js:31`), so each visit revalidates 2.5 MB by ETag. Cost: S.

**m4. Module waterfall.** `app.js` pulls 16 modules by chained imports, one round trip each on a cold load. Cost: S.

**m5. No service worker.** `manifest.webmanifest` exists but there is no offline support. Cost: M.

Checked and fine: point-in-polygon (antimeridian features are pre-split, all bboxes have west <= east; holes use even-odd), midnight rollover (30 s recheck, focus, visibility, UTC+14 timer, `app.js:279-301`), late-round marking, two-tab writes, keyboard play (`app.js:1041`), 44 px map controls (`styles.css:135`), GoatCounter (image ping, no script, origin-only referrer, `count.js`).

## 3. Readiness notes

**Step 2, own domain.** The intake already added a working nginx `Dockerfile` and `nginx.conf`. Staging serves at ends-of-the-earth-staging-295ebcf6ebb335bf.olympus-ai.cloud. Needed before launch:
- Cache headers: `index.html` and `s/*.html` no-cache; `?v=` assets `max-age=31536000, immutable`; JSON short with ETag. Today nginx sets none.
- Security headers: CSP, `X-Content-Type-Options`, `Referrer-Policy`, HSTS once HTTPS is stable.
- HTTPS via cert-manager or Cloudflare on the new domain.
- GitHub Pages cannot send 301s. Leave a stub repo whose `index.html` and `s/*.html` redirect by JS to the new domain, after the import path (C2) ships.
- Update `SITE_URL`, og tags and regenerate share pages (M3).
- The image is about 210 MB because of `s/` (192 MB).

**Step 3, iOS.** Capacitor works with this static site as-is. A bare wrapper will likely fail guideline 4.2. To pass, add: offline play (bundle data and decks), a local daily notification at the player's midnight, the native share sheet with the card image, and probably haptics or a widget. WKWebView storage is separate from Safari, so players start over unless import exists. The privacy label must cover GoatCounter.
